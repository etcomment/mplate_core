# Conventions

## Code

- TypeScript strict (`noUncheckedIndexedAccess` on), ES modules, Node ≥ 20. Imports use the `.js` extension.
- No `any`. No comments in code: names carry the meaning; explanations go in docs or ADRs.
- No abbreviations (`connection`, not `conn`; `index`, not `i` outside tiny lambdas is preferred).
- Functions are verbs (`drawBadge`, `measureTextStack`); booleans start with `is`, `has`, `can`.
- Pure functions outside the CLI and MCP I/O layers. No hidden side effects.
- Files stay under ~300 lines. No catch-all `utils` or `helpers` modules; shared layout helpers live in `packages/core/src/templates/shared.ts` and `radial.ts`.
- Zero runtime dependencies.

## Tests

- Vitest. Write the test that describes the behaviour, then the minimal implementation, then refactor.
- Parser, theme, text, render pipeline, CLI and MCP have unit tests. Templates are covered by `packages/core/tests/templates.test.ts` automatically.
- Never weaken the overlap or clipping checks to make a template pass; fix the layout or lower the template's `items.max`.

## Templates

- Original designs only (ADR-001).
- No colours or fonts in template code (ADR-005).
- The identity card example renders with zero diagnostics and appears in the gallery.

## Documentation

- English for code, docs, commits and issues.
- `docs/templates.md`, `docs/llm-guide.md` and `docs/gallery/` are generated by `npm run gallery`; never edit them by hand.
- Any DSL change updates `docs/dsl.md` in the same pull request.

## Versions

- Only the maintainer decides when the version number changes. Agents never bump it on their own; they record changes under `[Unreleased]` in `CHANGELOG.md` and ask.
- The project stays on `0.1.x` until the maintainer decides otherwise: each release increments the last number (`0.1.1`, `0.1.2`, …). npm and SemVer forbid leading zeros, so `0.1.001` is not a valid version.

## Git

- Branch from `main`; small pull requests.
- Commit format `type(scope): summary` (types: feat, fix, test, refactor, docs, chore), signed off (`-s`, DCO).
- CI runs typecheck, tests, build and checks that the gallery is up to date.
